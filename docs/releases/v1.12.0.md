## Telemachus Reborn v1.12.0 — Bar-tailed Godwit

### Features
- Add a CORS allowlist so browser dashboards on a different origin can read the API. Configure via a new `ALLOWED_ORIGINS` setting (comma-separated `scheme://host[:port]` entries) in `PluginData/Telemachus/config.xml`. Empty by default, which preserves the historical behaviour of never sending CORS headers — existing setups are untouched. Matching origins are echoed back exactly (no wildcard) with `Vary: Origin`, and the standard `OPTIONS` preflight is answered with `204`. (#82) *(Jon Pepler)*

### Bug Fixes
- Auto-defer attribute-based action handlers to the main Unity thread, so action endpoints no longer risk touching the game from a worker thread. (#81) *(Jon Pepler)*
- Propagate `AlwaysEvaluable` through `ActionAPIEntry` so action handlers marked always-evaluable are honoured. (#84) *(Jon Pepler)*

### Miscellaneous
- Broaden `AfterBuild.sh` portability — safe empty-array expansion under `set -u`, and `cp -pR` instead of the GNU-only `cp -ra`, so the post-build step works on macOS/BSD. (#87) *(Jon Pepler)*
- Repository moved to the **TeaGuild** organisation; version file, netkan, and README links updated to the new home.

### Documentation
- Document the `ALLOWED_ORIGINS` CORS configuration in the README.

### New Contributors
- [Jon Pepler (@jonpepler)](https://github.com/jonpepler) — CORS allowlist, action-handler threading fixes, build-script portability

### Bundled Houston (UI)
- Fixed the surface map's relief base layer. It requested a retired `color` tile style that 404/403s on every body; it now uses the live `biome` tiles (the same style Telemachus's own map already uses) and is relabelled **Biome**. Satellite and Slope layers were unaffected. (The KerbalMaps tile CDN itself is alive and serves over plain `<img>` — the earlier CORS/dead-server theory didn't hold up under testing.)
